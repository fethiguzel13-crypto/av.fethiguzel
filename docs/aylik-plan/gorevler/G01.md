# G01 — Kalite kapısı

**Amaç:** Tek komutla tip denetimi, lint, tüm test takımları (+ derleme) çalışsın; ay boyunca her commit
bu kapıdan geçsin.

**Dosyalar:**
- Yeni: `scripts/kalite.mjs` (adım listesi `ADIMLAR`, `testSayilari()` ayrıştırıcı, `logs/kalite-son.json`)
- Yeni: `scripts/__tests__/kalite.test.mjs` (ayrıştırıcı ve adım listesi testi)
- Değişen: `package.json` → `kalite:hizli`, `kalite`
- Rapor: `docs/aylik-plan/raporlar/kalite-baslangic.md`

**Adımlar:**
1. Her takımı ayrı ayrı çalıştır, süre ve sonucu kaydet (başlangıç).
2. `scripts/kalite.mjs` ve testini yaz; `test:quality` takımına dahil et.
3. Kırmızı olanları kök nedeniyle düzelt (tip hatası, kırık test). Lint çok gürültülüyse kapsamı uygulama
   koduna (app, components, lib) daralt; tek seferlik betik klasörleri ayrı ve yumuşak kalır — gerekçe raporda.
4. `npm run kalite:hizli` ve `npm run kalite` yeşil; süreler raporda.

**Kabul:** iki komut yeşil; `raporlar/kalite-baslangic.md` başlangıç/son durumunu sayılarla veriyor.
