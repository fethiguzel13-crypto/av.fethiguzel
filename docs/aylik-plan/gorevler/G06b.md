## Kök neden

Next 16 metadata'yı bölümler arasında yüzeysel birleştirir (`node_modules/next/dist/docs/01-app/03-api-reference/
04-functions/generate-metadata.md` → Merging). `app/layout.tsx` içindeki `alternates: { canonical: siteUrl,
languages: { 'tr-TR': siteUrl } }`, kendi `alternates` alanı olmayan her sayfaya miras kalır. Böylece bu sayfalar
ana sayfayı canonical ve hreflang olarak bildirir.

## Adımlar

1. Kırmızı testler `lib/__tests__/seo-metadata.test.mjs` (test:quality):
   - kök yerleşim `alternates` tanımlamaz,
   - `app/` altında www'siz canonical yok,
   - tablodaki her rota kendi canonical'ını tanımlar (sayfa ya da aynı klasördeki `layout.tsx`),
   - `public/sitemap-index.xml` yalnız robots.txt'deki haritaları gösterir.
2. Kökten `alternates` kaldırılır; tabloya göre metadata eklenir (başlık, açıklama, canonical). Metin reklam
   dili taşımaz; yalnız sayfanın içeriğini tarif eder.
3. `public/sitemap-index.xml` robots.txt'deki beş haritaya göre yeniden yazılır.
4. `/ingilizce-avukat` yönlendirmesi kalıcı yapılır ve site haritasından çıkarılır.
5. Kalan S5 maddeleri (`/pdf` 500, `/site-haritasi` Türkçe karakterli bağlantı) zaman kalırsa; kalmazsa ayrı adım.
6. `npm run kalite` (derleme dahil) + `next start` + `seo-tara`: canonical uyumsuz 0, varsayılan başlık tekrarı 0.

**Kabul:** testler önce kırmızı sonra yeşil; derlemede canonical uyumsuz 0; rapor `seo-baslangic.md`'ye G06b sonucu.
