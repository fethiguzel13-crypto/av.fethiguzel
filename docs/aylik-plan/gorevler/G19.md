## Tasarım

Üretilmiş not dosyasına (11.623 dosya) dokunulmaz. Elle yazılan, sürümlenen bir **kanonik katman** yalnız temsilci nota uygulanır:

`lib/ders-notlari/kanonik/<taban-kod>.json`

```json
{
  "ders": "borclar-genel",
  "guncelleme": "2026-10-09",
  "ornekOlaylar": [{ "baslik", "olay", "cozum", "sonuc", "dayanaklar": [Dayanak] }],
  "sinavIskeleti": [{ "adim", "aciklama" }],
  "tuzakDefteri": [{ "tuzak", "dogrusu", "dayanak": Dayanak }],
  "kisaTest": [{ "q", "choices": [4], "answer", "reason", "dayanak": Dayanak }],
  "kaynaklar": [{ "title", "url", "note" }]
}
```

`Dayanak = { kanun, madde, ifade }` G18 ile aynıdır: `ifade`, `content/mevzuat/<kanun>/madde-<n>.md` dosyasının kanun metninde
(`### Akademik` başlığından önceki kısım) aynen geçer. Doktrin görüşü, yazar adı ve içtihat künyesi katmana yazılmaz; yerel dosyası
olmayan kanuna dayanılmaz (gerekirse mevzuat.gov.tr'den doğrulanıp yerel dosya eksikliği soruya yazılır).

Katman `getNote` içinde değil, yalnız temsilci not için `kanonikKatmanUygula(note)` ile birleşir: `examples` katmanın olaylarıyla
değiştirilir, yeni alanlar (`sinavIskeleti`, `tuzakDefteri`, `kisaTest`) eklenir, kaynaklar birleşir. `DersNotuView` bu alanları
"Sınav iskeleti", "Tuzak defteri" ve "Kısa test" (mevcut `McqBlock`) bloklarıyla çizer; istemci betiği eklenmez.
