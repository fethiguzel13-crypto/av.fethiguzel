# G04 — API ve üyelik güvenlik denetimi

**Amaç:** Üyelik, ödeme ve ücretli arşiv uçlarındaki açıkları kapatmak; her düzeltme önce kırmızı testle
sabitlenir. Rapor: `raporlar/guvenlik-api.md`.

**Kapsam:** `app/api/uyelik/[...path]`, `app/api/yargi/[...path]`, `app/api/content-pack/[kanunId]`,
`app/api/pack-health`, `lib/uyelik/*`.

**Test düzeni:** `npm run test:uyelik` (gerçek `.ts` kaynağını `ts-register.mjs` ile yükler). `next/headers`
isteyen dağıtıcı (`handleUyelik`) doğrudan çağrılamaz; karar mantığı saf yardımcılara çıkarılır ve onlar test edilir.

(token sunucudan sunucuya kimlik doğrulamalı `retrieve` ile doğrulanıyor), oturum çerezi bayrakları
(httpOnly, üretimde secure, SameSite=Lax).

   `odeme/sonuc` (iyzico siteler arası POST) hariç.
