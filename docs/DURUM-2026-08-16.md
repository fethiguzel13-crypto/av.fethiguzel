
Doğrulanmamış hiçbir sayı yazılmadı. Değişken değerler (kıdem tavanı, TÜFE

### Bağımsız doğrulama yapıldı

31 rehberin **25 kilit iddiası**, resmî madde metinleri kaynak olarak
yüklenip NotebookLM'e sorularak bağımsız biçimde sınandı. Sonuç: içerik
hatası çıkmadı. İşaretlenen dört madde, sorunun kısaltılmış yazılmasından
kaynaklandı; rehber metinleri kapsamlıydı.

İki yerde ifade sıkılaştırıldı:
- ödeme emrine itiraz: icra inkâr tazminatında «reddedilen veya» eklendi
- mesafeli satış: otuz günlük sınırın istisnası kısa cevaba taşındı

NotebookLM burada **metin üretmek için kullanılmadı** — bu deponun tamamı
üretilmiş metnin zararını temizlemekle geçti. Yalnız kaynağa bağlı soru
sorma yeteneği, ikinci okuyucu olarak kullanıldı.

Yöntem ve tekrar çalıştırma:
[`lib/vatandas-rehberi/authored/README.md`](../lib/vatandas-rehberi/authored/README.md)

### Testler kaçamak ifadeyi engelliyor

## 4. Ek bulgular

### Sitede 81 görünmez CSS hatası

Tailwind, ölçek dışı opaklık değerlerini (`border-charcoal/8`) **hata
vermeden** üretmiyor. 32 dosyada 81 kullanım vardı; o kadar kenarlık ve zemin
hiç çizilmiyordu. Hepsi düzeltildi, denetleyici yazıldı:
`npm run lint:opacity`

### Resmî metinlerde OCR hasarı

8.087 maddenin **1.027'sinde** kelimeler ortadan bölünmüş: `re ddolunabilir`,
`zaman aşımı`, `mirasb ırakanın`.

Birleştirme denendi, sonra **durduruldu**: listenin onda biri OCR hatası değil,
meşru yazım varyantıydı (`ay başında` ≠ `aybaşında`). Bunları birleştirmek
resmî metni değiştirirdi.

Bunun yerine **arama boşluk duyarsız** yapıldı. Metin bayt bayt aynı; arama
iki yazımı da buluyor. Tanı raporu: `data/ocr-report.json`

**Kalıcı çözüm veri kaynağındadır** — metinler mevzuat.gov.tr'den yeniden
alınmalıdır.

### Resmî metin yerine özet konulmuş 23 madde

8.088 maddenin 23'ünde (%0,28) `official` alanı kanun metni değil, kanun metni
**hakkında** bir cümle taşıyor:

> *(Fıkra 2, 3, 4 ve 5 resmi madde metninde sırasıyla verilmiştir. …)*

22'si İSG paketinde, 1'i İş Kanunu m.120'de. Kullanıcı maddeyi okuduğunu
sanarken özet okuyor.

Bunlar artık `x: 1` bayrağıyla işaretleniyor ve Mevzuat uygulamasında sarı
uyarı şeridiyle gösteriliyor. Denetim: `node scripts/audit-official-text.mjs`

### Yargıtay arşivi karar metni içermiyor

`data/yargi-kararlari/index.jsonl` yalnız künye taşır; `decisions/` boş ve
anahtar kelime alanı 4.755 kaydın neredeyse tamamında boş. Bir kararın ne
dediği oradan öğrenilemez, bu yüzden rehberlerde karar atfı yapılmadı.

## 5. Buradan nasıl devam edilir

### Yeni rehber yazmak

```bash
# 1. Maddeyi doğrula
node scripts/madde.mjs is-kanunu 41 --tam

# 2. lib/vatandas-rehberi/authored/<slug>.ts yaz
#    Dosya başına hangi maddeden doğrulandığını yorum olarak koy

# 3. index.ts'e import ekle

# 4. JSON üret ve doğrula
node scripts/authored-to-json.mjs
npm run test:quality
npx tsc --noEmit

# 5. Siteye ve uygulamaya yansıt
node scripts/build-publishable-manifest.mjs
node scripts/build-bilgi-sitemap.mjs
cd mobile && node scripts/build-app.mjs --app=rehber
```

### Play Store yüklemesi

Ayrıntı: `mobile/docs/PLAY-STORE.md`

Önerilen sıra: **Hukuki Hesap** → bir hafta sonra Mevzuat → Vatandaş Hukuku →
İçtihat Günü. Dördünü aynı gün yüklemeyin.

Yapmanız gerekenler:

1. Yükleme anahtarı oluşturun — `mobile/scripts/create-upload-keystore.ps1`
2. Dört repo gizli anahtarını girin (`ANDROID_KEYSTORE_BASE64` vd.)
3. Actions → Build Android AAB → Run workflow
4. İlk yüklemeden **sonra** Play Console'dan SHA-256 alıp
   `public/.well-known/assetlinks.json` içindeki dört yer tutucuyu doldurun

### Ekran görüntüsü çekimi

Uygulamayı cihaza kurun, **uçak modunu açın**, öyle çekin. Uçak modunda dolu
görünen ekran, incelemecinin "gerçekten çevrimdışı mı" sorusunu ilk bakışta
cevaplar.
